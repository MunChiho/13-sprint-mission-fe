# 🐼 판다마켓

> 판다마켓 랜딩 페이지 로그인 회원가입을 HTML과 CSS로 구현한 프로젝트입니다.

---

## 📁 프로젝트 구조

- `index.html`: 랜딩 페이지
- `login.html`: 로그인 페이지
- `signup.html`: 회원가입 페이지
- `assets/*.css`: 공통 및 페이지 스타일
- `assets/`: 스타일시트와 이미지 폴더
- `assets/images`: 이미지 및 로고 파일

### 파일별 역할

| 파일          | 설명                                        |
| ------------- | ------------------------------------------- |
| `base.css`    | CSS 변수(`:root`), 공통 및 전역 스타일 정의 |
| `header.css`  | 헤더 영역 스타일                            |
| `footer.css`  | 푸터 영역 스타일                            |
| `section.css` | 메인 각 섹션의 스타일                       |
| `auth.css`    | 로그인 회원가입 공통 스타일                 |

---

## 🎨 디자인

`base.css`의 `:root`에 프로젝트에서 사용하는 색상과 레이아웃 값을 변수로 관리합니다.

### 레이아웃

| 변수명            | 용도           |
| ----------------- | -------------- |
| `--header-height` | 헤더 고정 높이 |
| `--page-width`    | 페이지 너비    |

### 색상 팔레트

| 변수명                    | 값        |
| ------------------------- | --------- |
| `--Primary-100`           | `#3692ff` |
| `--Primary-Primary-brand` | `#3692ff` |
| `--brand-blue`            | `#3692ff` |
| `--Cool-Gray-100`         | `#f3f4f6` |
| `--Secondary-50`          | `#f9fafb` |
| `--Secondary-200`         | `#e5e7eb` |
| `--Secondary-400`         | `#9ca3af` |
| `--Secondary-700`         | `#374151` |
| `--Secondary-900`         | `#111827` |
