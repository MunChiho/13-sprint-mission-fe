## 스프린트 1 요구사항

### 기본 — 랜딩 페이지

- [ ] React 등 UI 라이브러리 사용 없이 순수 HTML/CSS로 구현
- [ ] PC 사이즈 기준 디자인 구현
- [ ] Netlify 배포 ([참고](https://www.codeit.kr/learn/5309))
- [ ] 랜딩 페이지 URL: `/`
- [ ] `<title>` = **판다마켓**
- [ ] 로고 클릭 → `/`
- [ ] 로그인 버튼 클릭 → `/login` (빈 페이지)
- [ ] "구경하러 가기" 버튼 클릭 → `/items` (빈 페이지)
- [ ] Privacy Policy 클릭 → `/privacy`, FAQ 클릭 → `/faq` (모두 빈 페이지)
- [ ] SNS 아이콘(페이스북·트위터·유튜브·인스타그램) 클릭 → 새 창으로 각 홈페이지 이동
- [ ] GNB(로고 + 로그인 버튼) 스크롤 시 상단 고정
- [ ] 너비 ≥ 1920px: 배경은 꽉 채우고, 내부 요소 위치 고정, 여백만 증가
- [ ] 너비 < 1920px: 로고 왼쪽 여백 200px / 로그인 버튼 오른쪽 여백 200px 유지, 두 요소 간 거리 좁아짐
- [ ] 너비 ≥ 1920px: 내부 요소 동일 간격 유지하며 가운데 정렬
- [ ] 너비 < 1920px: 하단 "codeit-2024" 왼쪽 200px / SNS 아이콘 오른쪽 200px 유지, Privacy·FAQ와 균등 간격 유지
- [ ] 클릭 가능한 요소에 `cursor: pointer` 적용

### 심화 — 공통

- [ ] `reset.css` 적용
- [ ] 모든 크기 값(간격·요소 크기·font-size 등)을 브라우저 기본 폰트 크기에 따라 유동적으로 변하도록 설정
