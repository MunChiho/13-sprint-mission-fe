# 프로젝트 이름

판다마켓 로그인, 회원가입 페이지

## 소개

로그인 페이지와 회원가입 페이지를 피그마에 있는 디자인을 바탕으로 코드 작성하여 만들었습니다

## 기능

- 로고를 클릭하면 루트 페이지로 이동
- 하단의 로그인 또는 회원가입 을 누르면 해당 페이지로 서로 이동 가능함
- 간편 로그인하기의 sns아이콘들을 클릭할시, 해당 sns 링크로 이동

## 기술 스택

- HTML/CSS
